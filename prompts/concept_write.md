## 第一步：选叙事载体（先判断概念，再选载体；不固定用寓言）

好的载体让读者跟着走完，等于先"看见"了机制运转。判断标准：这个概念的机制哪一面最难用嘴讲清楚，就选能把它演出来的载体。从下面选**最适合本概念**的一种：

1. **寓言故事**：把机制装进一个原创的日常故事，主角的处境天然就是机制在运转，有起承转合。适合能具象成人物行动的概念（复利、通货膨胀）。
2. **场景推演**：跟着一个具体的人、家庭或小店，在真实情境里把机制一步步走完，每一步指出发生了什么。适合就发生在读者生活里、但没人点破的概念（沉没成本、锚定效应）。
3. **反直觉现象**：从一个人尽皆知但没人细想的现象切入，层层追问"为什么会这样"，最后落到概念。适合误解率高的概念（机会成本、幸存者偏差）。
4. **历史真实事件**：用一个常识级的历史事件当载体（只用公认事实，不编细节）。适合有时间张力、有结局反差的事件型概念（泡沫、挤兑）。
5. **思想实验**：一个假设情境加严格推演（明确说"假设"）。适合抽象但逻辑链短的概念（囚徒困境、边际效用）。

载体纪律：

- 全文只用一个载体，讲透，不混用；
- 载体里的因果必须和概念的真实机制一一对应，不为好听扭曲逻辑；
- 载体阶段不出现概念名；
- 后文要用的概念，读者要么本来就懂，要么载体已经演过，没铺垫过的不能直接用。

## 第二步：结构（按理解节奏走，段落类型固定）

1. **hook 场景钩子（1 段）**：从读者生活中的具体困境或反差写起，第一句就是钩子——3 秒内让人想往下看。不许"从前""很久以前"式开场，不许提前说出概念名。
2. **story 叙事载体（3-5 段）**：载体本体，按所选载体的写法推进（故事有起伏，推演有步骤，追问有层次）。
3. **reveal 揭示（1 段）**：在读者已经"看见"机制运转的时刻点破——"这就是**{{concept}}**"，并给一句话定义。位置随载体走（通常全文 40-60% 处），以"读者已经看见了"为准，不猜谜到最后。
4. **explain 讲透（3-4 段）**，全文重头：
   - 从第一性原理拆解机制：为什么会这样，最基本的因果链是什么；
   - **隐喻对照**：把载体里的每个关键元素逐个映射回现实（载体里的鸡蛋=本金，借出去的蛋=产生的利息……），可以用清单式写法；
   - 澄清这个概念**最常被误解的一点**。
5. **extend 克制的延伸（1-2 段）**：只给 1-2 个"懂了这个之后你能做什么"的行动推论。不引入新概念，不开新坑——这个概念必须在本文讲完。
6. **cta 互动（1 段）**：一个具体的轻提问，贴近读者自身处境。

## 硬规则

1. **零门槛**：任何术语第一次出现当场用生活语言翻译；数字用整数和倍数（"翻了 3 倍"），不堆百分比和小数；例子只用公认常识，**不编造精确数据、机构名、法规条款**；举例需假设时明说"假设"。
2. **数字要有说服力（增长/累积类概念必守）**：
   - 载体里的增速、时间、终值必须**经得起心算验算**，三者自洽；
   - 终值与初值必须**拉开数量级**——时间跨度很长而倍数平平（比如三十年才翻十几倍），说服力为零。解法三选一：拉长时间跨度（三五十年以上）、提高增速假设、把镜头对准**后段爆发**（明确写出"最后 N 年新增的，比之前所有年份加起来还多"这一标志性瞬间）；
   - 写完自查：一个陌生读者看到终值，会不会"咦，就这？"——会，就重设数字。
3. **第一性原理**：解释"为什么"推到最基本的因果，不停留在术语换术语；绝不用一个技术或金融概念去解释另一个概念。
4. **讲透不留尾巴**：读者读完不需要看第二篇就能完整理解这个概念；延伸内容必须在概念讲透之后，且不得开新坑。

6. **篇幅**：全文 {{min_length}}-{{max_length}} 字，每段 1-4 句、80-200 字，短段落节奏。写不满就深挖载体细节和机制推演，不许注水重复；超了砍素材，不硬塞。
