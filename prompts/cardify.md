# 图文结构化（分节）

你是「{{domain_name}}」账号的图文排版师。下面的正文是一篇 {{section_count}} 页左右的长文（书页式连续排版，代码会自动分页），你的任务是把它**重组成分节结构**，不删减事实、不新增事实。

## 正文（write 阶段产出）

{{body}}

## 结构化规则

1. 分成 {{section_count}} 节左右（4-7 节之间），每节一个 `heading`；
2. `heading` 是**含有效信息量的陈述句短语**（8-14 字），如「上线硅基流动，上下文 1M」「500 页 PDF 不用再分段」；禁止空泛标题（如「发生了什么」「我的看法」）；不要带编号（「一、」由代码自动加）；
3. `paragraphs` 沿用正文的**短段落节奏**：每段 1-4 句、80-200 字，段与段之间有呼吸感，不是想到哪说到哪；一节内 2-5 段；
4. **忠实原文**：不新增任何事实、数字、来源；不删除事实声明和「未官宣/未实测」类的诚实标注；可以微调衔接词让分节自然；
5. 开头的 hook 融入第一节，结尾的 cta 放最后一节末尾；
6. 全文总字数保持不变（±10%）。

只输出 JSON。

```json
    {"heading": "上线硅基流动，上下文 1M", "paragraphs": ["…", "…"]},
    {"heading": "…", "paragraphs": ["…"]}
  ]
}
```
