# 卡片排版规范（书页式连续排版）

> 定稿：2026-09-03 ｜ 引擎：`render/flow_cards.py` ｜ 领域配置：`domains/<id>/config.yaml` 的 `cardify` 块

## 排版规则

1. **跨卡连续接力**：内容是一条流，卡片排满即翻页；节标题内联在流中，可出现在任意页中部。
2. **孤行保护**：标题不落卡底（后随至少 2 行正文）；段落首行不孤悬页底（至少 2 行同页）。
3. **段落可跨页续排**（真书页流），跨页处不加段前距。
4. **避头尾**：行首禁则标点（，。」等）连锁下推；行末不悬开引号；破折号——成对不拆行。
5. **散文模式**：`cardify.use_headings: false` 时无节标题，纯段落流。

## 文案密度契约

- `write` 阶段：全文 2800-3500 字，12-18 个段落，每段 1-4 句、80-200 字，短段落节奏。
- `cardify` 阶段（LLM 只做结构化）：正文重组为 4-7 节，节标题为 8-14 字含信息量陈述句（编号由代码加）；段落节奏保持；不增删事实。
- 分页由代码确定性完成，不消耗 token；单篇容量约 10 页，超出部分舍弃（正常由字数契约兜住）。

## 渲染

- HTML → Chrome headless 截图（`--window-size=1080,1800`），PNG 内嵌 sRGB。
- 字体走 Google Fonts，失败时回退本机宋体，不阻塞出图。
